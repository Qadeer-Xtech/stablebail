# Security Policy

## Reporting a vulnerability

Please do NOT open a public issue for a security problem.

- Preferred: use GitHub's private vulnerability reporting on this
  repository (Security tab -> "Report a vulnerability").
- The maintainers aim to acknowledge a report within 48 hours.

## Scope notes

stablebail is a fork of @whiskeysockets/baileys (MIT). Vulnerabilities
that also exist upstream will be reported upstream as well; fixes
land here as new patch versions and are listed in CHANGELOG.md.
